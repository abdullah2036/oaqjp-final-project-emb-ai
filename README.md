# Final project

Emotion Detection web application built with the embeddable Watson NLP libraries
and deployed with Flask.

## Structure

```
final_project/
├── EmotionDetection/
│   ├── __init__.py
│   └── emotion_detection.py
├── static/
│   └── mywebscript.js
├── templates/
│   └── index.html
├── server.py
├── test_emotion_detection.py
└── README.md
```

## Run

```
python3 server.py
```

Then open http://localhost:5000
